# Admin API

The write surface is documented as the **[Management API](./management-api.md)** — use that page for site-building agents.

Summary:

- Auth: `Authorization: Bearer <JWT | aur_… API token>`
- CRUD: `/api/v1/admin/content-types…`, fields, entries, publish
- Bulk: `POST /api/v1/admin/provision`
- Tokens: `/api/v1/admin/tokens`

Human editors can also use the Admin studio at `http://localhost:3001`.
